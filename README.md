# Portfolio

Hey — you've landed on the code behind my portfolio. Feel free to poke around.

I'm Thomas, a software engineer in Bengaluru. The site is where I write up the
things I've built: backend systems, GenAI stuff, some ML and blockchain, and
the frontends for my own projects.

**[Have a look at the actual site →](#)**

## Where things are

src/data/projects.json   all the content — every project lives here
src/pages/Home.jsx       the landing page
src/pages/Project.jsx    renders every case study
src/styles.css           colours, type, both themes
public/                  icons and the share card

React + Vite + React Router. No CSS framework, no backend, nothing clever.

## Run it

npm install
npm run dev

That's it. If something here is useful to you, take it.
